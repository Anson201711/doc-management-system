## 详细测试用例

### PC-01: 分配角色

| 字段 | 内容 |
|------|------|
| **用例ID** | PC-01 |
| **用例名称** | 分配角色 |
| **测试目的** | 验证管理员可以为用户分配角色 |
| **优先级** | P0 |
| **前置条件** | 用户存在，系统管理员登录 |
| **测试步骤** | 1. 系统管理员登录<br>2. 调用分配角色接口: `POST /api/users/{userId}/role`<br>3. 传入角色ID: "role_dept_manager"<br>4. 确认分配 |
| **预期结果** | 1. 分配成功<br>2. 用户拥有新角色<br>3. 返回成功提示<br>4. 响应状态码 200 |
| **后置条件** | 用户角色已更新 |

### PC-02: 查询角色列表

| 字段 | 内容 |
|------|------|
| **用例ID** | PC-02 |
| **用例名称** | 查询角色列表 |
| **测试目的** | 验证可以查询系统中所有角色 |
| **优先级** | P0 |
| **前置条件** | 无 |
| **测试步骤** | 1. 用户登录<br>2. 调用查询角色列表接口: `GET /api/roles` |

### PC-03: 文档权限设置

| 字段 | 内容 |
|------|------|
| **用例ID** | PC-03 |
| **用例名称** | 文档权限设置 |
| **测试目的** | 验证文档所有者可以为文档设置访问权限 |
| **优先级** | P0 |
| **前置条件** | 文档已创建，用户是文档所有者 |
| **测试步骤** | 1. 文档所有者登录<br>2. 获取文档ID<br>3. 调用权限设置接口: `PUT /api/documents/{id}/permissions`<br>4. 传入权限配置:<br>&nbsp;&nbsp;- 用户A: 读取权限<br>&nbsp;&nbsp;- 用户B: 读写权限<br>&nbsp;&nbsp;- 部门: 仅查看 |
| **预期结果** | 1. 设置成功<br>2. 返回更新后的权限配置<br>3. 响应状态码 200 |
| **后置条件** | 文档权限已更新 |

---

### PC-04: 权限验证

| 字段 | 内容 |
|------|------|
| **用例ID** | PC-04 |
| **用例名称** | 权限验证 |
| **测试目的** | 验证系统正确执行权限控制，用户只能访问授权的资源 |
| **优先级** | P0 |
| **前置条件** | 文档权限已设置 |
| **测试步骤** | 1. 用户A (仅有读取权限) 登录<br>2. 尝试访问文档: `GET /api/documents/{id}`<br>3. 尝试更新文档: `PUT /api/documents/{id}`<br>4. 用户B (有读写权限) 登录<br>5. 尝试访问文档<br>6. 尝试更新文档 |
| **预期结果** | 1. 用户A: 读取成功，更新被拒绝，返回403<br>2. 用户B: 读取成功，更新成功<br>3. 无权限用户: 访问被拒绝，返回403 |
| **后置条件** | 无 |

---

### PC-05: 权限继承

| 字段 | 内容 |
|------|------|
| **用例ID** | PC-05 |
| **用例名称** | 权限继承 |
| **测试目的** | 验证子文件夹可以继承父文件夹的权限 |
| **优先级** | P1 |
| **前置条件** | 父文件夹已设置权限 |
| **测试步骤** | 1. 父文件夹已设置权限<br>2. 在父文件夹下创建子文件夹<br>3. 查询子文件夹权限<br>4. 验证是否继承父文件夹权限 |
| **预期结果** | 1. 子文件夹自动继承父文件夹权限<br>2. 可单独覆盖子文件夹权限<br>3. 继承的权限与父文件夹一致<br>4. 响应状态码 200 |
| **后置条件** | 子文件夹权限已设置 (继承或自定义) |

## 测试数据

### 系统角色

| 角色ID | 角色名称 | 描述 | 权限 |
|--------|----------|------|------|
| role_admin | 系统管理员 | 系统管理最高权限 | 全部权限 |
| role_dept_manager | 部门主管 | 管理部门文档 | 创建、读取、更新、删除、分享 |
| role_creator | 文档创建者 | 创建和管理自己文档 | 创建、读取、更新、删除自己的文档 |
| role_viewer | 文档查看者 | 只读访问 | 读取已分享的文档 |

### 权限类型

| 权限代码 | 权限名称 | 说明 |
|----------|----------|------|
| READ | 读取 | 查看文档内容 |
| WRITE | 写入 | 修改文档内容 |
| DELETE | 删除 | 删除文档 |
| SHARE | 分享 | 将文档分享给其他用户 |
| DOWNLOAD | 下载 | 下载文档 |
| ADMIN | 管理 | 管理文档权限 |

## API接口清单

| 接口路径 | 方法 | 说明 |
|----------|------|------|
| `/api/roles` | GET | 查询角色列表 |
| `/api/users/{userId}/role` | POST | 分配角色 |
| `/api/users/{userId}/role` | GET | 查询用户角色 |
| `/api/documents/{id}/permissions` | GET | 查询文档权限 |
| `/api/documents/{id}/permissions` | PUT | 设置文档权限 |
| `/api/folders/{id}/permissions` | GET | 查询文件夹权限 |
| `/api/folders/{id}/permissions` | PUT | 设置文件夹权限 |
