## 详细测试用例

### UC-01: 用户注册成功

| 字段 | 内容 |
|------|------|
| **用例ID** | UC-01 |
| **用例名称** | 用户注册成功 |
| **测试目的** | 验证新用户可以成功注册系统 |
| **优先级** | P0 |
| **前置条件** | 无 |
| **测试步骤** | 1. 打开注册页面<br>2. 输入用户名: `testuser001`<br>3. 输入邮箱: `testuser001@example.com`<br>4. 输入密码: `Test123456`<br>5. 确认密码: `Test123456`<br>6. 点击注册按钮 |
| **预期结果** | 1. 注册成功，系统返回成功提示<br>2. 自动跳转至登录页面或直接登录<br>3. 数据库中新增用户记录<br>4. 返回Token |
| **后置条件** | 用户被创建，可用于登录 |

| 字段 | 内容 |
|------|------|
| **用例ID** | UC-02 |
| **用例名称** | 用户登录成功 |

| **优先级** | P0 |
| **前置条件** | 用户已注册 (用户名: `admin`, 密码: `admin123`) |

| **预期结果** | 1. 登录成功，跳转至首页<br>2. 页面显示用户信息<br>3. JWT Token已存储<br>4. 响应状态码 200 |
| **后置条件** | 用户处于登录状态，Token已保存 |

### UC-03: 用户登录失败(密码错误)

| 字段 | 内容 |
|------|------|
| **用例ID** | UC-03 |
| **用例名称** | 用户登录失败(密码错误) |
| **测试目的** | 验证密码错误时系统正确拒绝登录 |
| **优先级** | P0 |
| **前置条件** | 用户已注册 (用户名: `admin`, 密码: `admin123`) |
| **测试步骤** | 1. 打开登录页面<br>2. 输入用户名: `admin`<br>3. 输入错误密码: `wrongpassword`<br>4. 点击登录按钮 |
| **预期结果** | 1. 登录失败，页面显示错误提示<br>2. 错误提示: "用户名或密码错误"<br>3. 响应状态码 401<br>4. 不返回Token |
| **后置条件** | 用户仍处于未登录状态 |

### UC-04: Token刷新

| 字段 | 内容 |
|------|------|
| **用例ID** | UC-04 |
| **用例名称** | Token刷新 |
| **测试目的** | 验证系统可以刷新过期的JWT Token |
| **优先级** | P0 |
| **前置条件** | 用户已登录，获得有效Token |
| **测试步骤** | 1. 用户登录获取Token<br>2. 调用刷新Token接口: `POST /api/auth/refresh`<br>3. 使用当前Token作为Refresh Token |
| **预期结果** | 1. 刷新成功<br>2. 返回新的Access Token<br>3. 响应状态码 200<br>4. 新Token有效期重新计算 |
| **后置条件** | 用户Token已更新 |
