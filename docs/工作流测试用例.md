## 详细测试用例

### WF-01: 创建审批流程

| 字段 | 内容 |
|------|------|
| **用例ID** | WF-01 |
| **用例名称** | 创建审批流程 |
| **测试目的** | 验证管理员可以创建审批流程 |
| **优先级** | P0 |
| **前置条件** | 管理员已登录 |
| **测试步骤** | 1. 进入流程管理页面<br>2. 点击"新建流程"<br>3. 填写流程名称: `请假申请`<br>4. 选择流程类型: `请假`<br>5. 配置审批节点: 部门经理 -> HR<br>6. 设置审批规则<br>7. 点击保存 |
| **预期结果** | 1. 流程创建成功<br>2. 流程显示在流程列表<br>3. 流程配置正确保存 |
| **后置条件** | 流程可用于提交申请 |

### WF-02: 提交审批申请

| 字段 | 内容 |
|------|------|
| **用例ID** | WF-02 |
| **用例名称** | 提交审批申请 |
| **测试目的** | 验证用户可以提交审批申请 |
| **优先级** | P0 |
| **前置条件** | 流程 `请假申请` 已创建，用户已登录 |

| **预期结果** | 1. 申请提交成功<br>2. 审批人收到待办通知<br>3. 申请状态变为"审批中"<br>4. 提交记录可在"我的申请"中查看 |
| **后置条件** | 审批流程启动 |

### 审批状态说明

| 状态 | 说明 |
|------|------|
| draft | 草稿 |
| pending | 待审批 |

| rejected | 已拒绝 |

### 优先级说明

- **P0**: 核心功能，必须测试
- **P1**: 重要功能，建议测试
- **P2**: 辅助功能，可选测试
