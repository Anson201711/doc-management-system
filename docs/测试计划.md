## 1. 测试范围

### 1.1 测试对象
- 前端: React 18 + Ant Design
- 后端: Spring Cloud 微服务 (9个服务)
- 接口: REST API

### 1.2 功能模块
| 模块 | 说明 |
|------|------|
| 用户模块 | 注册、登录、登出、Token验证 |
| 文档模块 | CRUD、版本控制、搜索 |
| 权限模块 | 角色、权限、分享 |
| 工作流模块 | 审批、流程 |
| 通知模块 | 站内通知 |
